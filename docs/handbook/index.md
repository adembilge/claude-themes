# Introduction

Claude-Themes adds 40 theme families to the Code tab in Claude Desktop. Every family has a light and dark variant. Use the gallery to try them, or build a palette from an accent color in Theme Maker.

## Getting started

1. Follow [Installation](installation.md#install-the-plugin) in a local Code session on macOS or Windows.
2. Open the gallery with the command below. Choose **Dark** or **Light**, then select a theme card to apply it.
3. Star a palette to find that variant again under **Favorites**.

```text
/claude-themes
```

To switch without opening the gallery, try `/claude-themes github light`. [Browse Themes](themes.md#switch-from-the-prompt) explains what happens when you omit the mode.

## Where colors apply

Applying a Desktop theme changes the Code tab. The Plugins and Artifacts pages keep their own appearance. The Claude Code CLI reads a separate theme file, and your terminal emulator has its own color settings. See [how the three surfaces differ](terminal.md#desktop-cli-and-terminal-colors).

The **Themes** control on the documentation site previews colors in your browser. Use the gallery in Claude Desktop to apply a palette there.
