    How to use it

    1. Install the plugin in Claude Code: 
      /plugin marketplace add adembilge/claude-themes
/plugin install desktop-themes@claude-themes
    2. Open /claude-themes and go to the Theme Maker tab.
    3. Paste this link, or the theme code, in Import and press Enter.
