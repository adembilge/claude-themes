Install Claude-Themes

Open a local session in Claude Desktop’s Code tab on macOS or Windows.

Run both commands separately. Restart the session, then run /claude-themes to open the gallery.

/plugin marketplace add adembilge/claude-themes
/plugin install desktop-themes@claude-themes
