# Security policy

Report a suspected vulnerability through the [private GitHub reporting form](https://github.com/adembilge/claude-themes/security/advisories/new). Sign in to GitHub and keep the details in the private report while the maintainers review it.

Include the following where available.

- The Claude-Themes plugin version or commit, Claude version, and operating system.
- The affected behavior and its security impact.
- Steps to reproduce it, including a minimal sample or sanitized logs if they help.

Remove credentials, private paths, and personal data from attachments. Use [GitHub Issues](https://github.com/adembilge/claude-themes/issues) for ordinary bugs and feature requests.
